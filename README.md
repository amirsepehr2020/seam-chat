# SEAM CHAT

A polished, animated web messenger concept built from scratch for the SEAM CHAT project.

## ✨ Highlights

- Purple + green visual identity
- Custom SVG SEAM CHAT brand mark in `assets/seam-chat-logo.svg`
- Glassmorphism panels with neon ambient lighting
- Animated message reveals, typing indicator and media preview
- Conversation search with `Ctrl/Cmd + K`
- Functional message composer
- Chat selection and notification toggle interactions
- Responsive layout for smaller screens
- Reduced-motion accessibility support

## Run

No build step is required for the current static frontend. Open `index.html` in a modern browser or serve the repository with any static web server.
